## Описание модулей и функций
### Модуль masks
1. Функция **get_mask_card_number** для маскировки номера банковской карты
Принимает на вход номер карты и возвращает ее маску в формате XXXX XX** **** XXXX,
где X — это цифра номера. Остаются видимыми только первые 6 цифр и последние 4 цифры, номер разбит по блокам по 4 цифры.
Пример работы функции:
Входной аргумент: 7000792289606361
Выход: 7000 79** **** 6361
2. Функция **get_mask_account** для маскировки номера банковского счета
Функция принимает на вход номер счета и возвращает его маску в формате **XXXX,
где X — это цифра номера. Остаются видимыми только последние 4 цифры номера.
Пример работы функции:
Входной аргумент: 73654108430135874305  
Выход: **4305
### Модуль widget
1. Функция **mask_account_card** для обработки информацию как о картах, так и о счетах.
Принимает один аргумент — строку с типом и номером карты или счета и возвращает строку с замаскированным номером.
#### Примеры работы функции:
#### Для карты
Входной аргумент: Visa Platinum 7000792289606361
Выход: Visa Platinum 7000 79** **** 6361
##### Для счета
Входной аргумент: Счет 73654108430135874305
Выход: Счет **4305
2.  Функция **get_date**
Принимает на вход строку с датой в формате **"2024-03-11T02:26:18.671407"**
 и возвращает строку с датой в формате **"ДД.ММ.ГГГГ"**
Пример: ("11.03.2024").
### Модуль processing
1. Функция **filter_by_state**
Принимает список словарей и опционально значение для ключа state (по умолчанию 'EXECUTED').
Возвращает список словарей, содержащий только те словари, у которых ключ "state" соответствует указанному значению.
#### Пример: выход функции со статусом по умолчанию 'EXECUTED':
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
 {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]

2. Функция **sort_by_date**
Принимает список словарей и необязательный параметр - порядок сортировки (по умолчанию — убывание).
Возвращает новый список, отсортированный по дате (date).
